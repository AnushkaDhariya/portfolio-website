## ✨ Key Features

- **📱 Fully Responsive Design:** Built using Bootstrap 5's 12-column grid system (`col-12`, `col-md-4`, `col-md-8`) for seamless experience across mobile, tablet, and desktop screens.
- **🧭 Smooth Navigation:** Sticky navbar featuring collapsible mobile toggle and smooth scrolling offsets.
- **💻 Technical Stack Cards:** Clean visual cards categorized into Frontend, Data Science/ML, and Analytics.
- **📊 Interactive Projects Table:** Structured showcase highlighting core academic and analytical projects with status tags.
- **📬 Contact Integration:** Clean centered form layout configured with standard form controls.
